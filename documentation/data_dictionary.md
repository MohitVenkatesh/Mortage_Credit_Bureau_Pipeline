# Data dictionary

| Field | Meaning |
|---|---|
| application_id | Unique mortgage application identifier |
| applicant_id | Stable applicant join key across sources |
| loan_amount | Requested mortgage amount |
| property_value | Property purchase/appraised value used for LTV |
| monthly_gross_income | Applicant monthly gross income |
| fico_score | Credit bureau score |
| monthly_debt | Existing monthly debt obligations |
| ltv_pct | Loan-to-value percentage |
| dti_pct | Debt-to-income percentage |
| decision | APPROVED, DECLINED or CO_SIGNER_REQUIRED |
| reason_code | Machine-readable decision explanation |
